# Сборка Save Log

GitHub Actions собирает Linux-образ из коммита и публикует его в GitHub Container Registry после отдельной проверки без сети. Откройте итог успешного запуска **Build Save Log image** и возьмите ссылку вида `ghcr.io/…@sha256:…`. Используйте тот же digest для обоих ботов после проверки совместимости каждого окружения.

У каждого бота свои закрытые настройки, база данных, секрет вебхука и HTTPS-адрес. Для загрузки закрытого образа на VPS используйте доступ на чтение пакета. GitHub Actions только собирает образ.

## Схема и запуск

Образ проверяет схему до запуска приложения. Для новой изолированной базы предусмотрена миграция `clean_20261011_01`. Для совместимой базы на этой ревизии оператор отдельно применяет [изменение полей канала](channel_access_columns.sql) внутри транзакции с `lock_timeout` и `statement_timeout`. Файл добавляет два поля таблицы `required_channels` и сохраняет ревизию Alembic. Совместимость существующей базы проверяйте на восстановленной копии перед переключением бота.

При первом запуске с боевым токеном приложение регистрирует HTTPS-адрес в Telegram. При переносе сначала проверьте восстановление истории и настроек, поведение образа и доступность HTTPS, затем переключите один экземпляр бота на VPS. Сохраните прежний образ и закрытые настройки для отката.
